# PySpark for Data Engineering - course code

Code for the video course **PySpark for Data Engineering**: [YOUTUBE_LINK_PLACEHOLDER]

Everything here was typed live in the video, chapter by chapter. It is learning code, not production code.
Everything runs locally on one machine (Spark in local mode). No cloud account is needed.

## What's inside

| Chapter | Files |
|---|---|
| 2 Setup | `hello_spark.py` |
| 3 SparkSession, first DataFrames | `spark_session.py`, `dataframes.py` |
| 4 Course data | `make_data.py` (synthetic shop data: products, customers, daily messy order files, fixed seed) |
| 5 Reading files | `read_files.py` |
| 6 Schemas and bad records | `schemas.py`, `read_typed.py`, `bad_records.py`, `data/bad_orders.csv` (a tiny hand-typed sample of broken rows) |
| 7-8 Transformations, aggregations | `sources.py`, `transform.py`, `aggregate.py` |
| 9-11 Joins, windows, Spark SQL | `joins.py`, `windows.py`, `spark_sql.py` |
| 12 UDFs | `udfs.py` |
| 13 Nulls and duplicates | `nulls_dupes.py`, `cleaning.py` |
| 14 Partitioned Parquet | `write_lake.py`, `read_lake.py` |
| 15-16 Plans, caching, performance | `lazy.py`, `perf.py` |
| 17 Incremental loads and upserts | `incremental.py` |
| 18 Data quality | `quality.py` |
| 19-20 Final project | `etl.py` (star schema), `explore_star.py`, `aggregates.py`, `report.py`, `run_pipeline.sh` |

See `HOW_TO_RUN.txt` for the exact commands, in course order.

## Data

All data is synthetic. It is generated by `make_data.py` with a fixed seed, so you get the same numbers as the video.
No third-party dataset is used, and no generated data is included: run the code to create it.

## Requirements

Java 17 or 21 (tested with OpenJDK 21), Python 3.10+ (tested with 3.13.5), pyspark 3.5.9.
Linux, macOS, or WSL on Windows.
